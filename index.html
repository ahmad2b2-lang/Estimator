Equipment Types Module

Add equipment type

Variant is optional — use it when the same equipment comes in versions with different specs (the ⧉ button duplicates a row for that). After adding, tap the cells in its row to enter the number of drawings needed per one unit.

Tap any cell to edit. Saved automatically in this browser.

Rename drawing types

Paste the list and it is applied in order to the existing types (extra entries add new types). Accepted formats: two Excel rows (row 1 = abbreviations, row 2 = full names), one line per type as ABBR [tab] Full name, or just one full name per line. Column headers show the abbreviation; the full name appears when you tap/hover it.

Import equipment types from Excel / CSV

First row = headers: Discipline, Equipment, then one column per drawing type (drawings needed per ONE unit). Discipline must be one of Electrical, Flare, Process, Utility (other rows are skipped). An optional Variant column is supported. Existing equipment with the same Discipline + Name + Variant is updated; new ones are added. Columns named Plant / Quantity are ignored.

Drawing Quantities Module

Calculated from the Drawings Register Module. Each drawing type has one size, so its quantity appears in the column of that size. Equivalent A-size = quantity × the factor of its size (editable above; leave a factor empty if that size is not used).
